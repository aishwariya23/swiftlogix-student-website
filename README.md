# SwiftLogix Student Website

A beginner-friendly website project created for teaching the basic structure of a webpage.

## Files

- `index.html` — webpage structure and content
- `style.css` — colours, spacing, layout, and responsive design
- `script.js` — simple shipment tracking interaction

## Sections in the webpage

1. Header
2. Navigation
3. Hero / main banner
4. Track Your Shipment form
5. Why SwiftLogix feature cards
6. Recent Shipment section
7. Footer

## Run locally

Open `index.html` in a browser.

For VS Code, you can also use the Live Server extension.

## Test shipment IDs

- `S101` → Delivered
- `S102` → In Transit
- `S103` → Delayed

## GitHub Pages

1. Upload these files to a GitHub repository.
2. Open the repository **Settings**.
3. Go to **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/root` folder.
6. Save.

GitHub will provide a public website URL.
